# Масштабирование VIP — лендинг

Вёрстка по Figma-макету: видео, форма заявки с UTM-метками, билет,
карусель, тикер, футер. Полностью адаптивно (desktop / mobile).

## Структура

```
index.html
assets/
  css/style.css
  js/main.js
  images/
```

## Что нужно доделать перед сдачей

Вся графика уже выгружена из макета и лежит в `assets/images/`:
`hero-bg.webp` / `offer-bg.webp` (фоны секций), `ticket.webp` (билет целиком
картинкой), `arrow-label.webp` (стрелка с плашкой «Только 47 билетов»),
`check.webp` (иконка-галочка в списках), `gallery-1.webp`…`gallery-6.webp`
(карусель). Обложка видео отдельно не нужна — она подтягивается
автоматически с YouTube по ссылке на ролик.

1. **Шрифт заголовков.** В макете использован Bebas Neue Cyrillic — его нет
   в Google Fonts, поэтому сейчас стоит Oswald (похожий по духу, тоже
   бесплатный, с кириллицей). Если у вас есть лицензионные файлы Bebas Neue
   Cyrillic — киньте .woff2, подключим через `@font-face` и поменяем одну
   переменную `--font-display` в `assets/css/style.css`, остальное трогать
   не придётся.

2. **CRM.** В `assets/js/main.js` есть готовый обработчик отправки формы:
   он проверяет поля, собирает имя/email/телефон/название задачи
   («Контакты МБР+тренинг (ПК1)») и все UTM-метки из URL, и сейчас просто
   уводит на страницу «спасибо» — вызов к Laravel CRM ещё не подключен.
   Как только дадите эндпоинт и доступы, добавим `fetch` перед редиректом
   на `THANK_YOU_URL`. Форма при этом уже полностью тестируема: заявки
   видно в консоли браузера (F12 → Console).

3. **Мелочи, которые нужно уточнить у клиента:**
   - ссылка на Telegram сейчас заглушка (`https://t.me/`) — нужен реальный юзернейм/бот;
   - «Дистанционный договор» в футере ведёт в никуда (`#`) — нужен файл или страница;
   - email/копирайт-год уже настоящие (год подставляется автоматически).

## Локальный просмотр

Просто открыть `index.html` в браузере — сайт статический, сервер не нужен.
Для проверки формы удобнее через локальный сервер (иначе некоторые браузеры
капризничают с относительными путями):

```bash
cd путь/к/папке/с/сайтом
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Деплой на GitHub Pages

1. Создайте новый репозиторий на GitHub (например, `scaling-vip-landing`).
2. Загрузите туда все файлы этого проекта (сохраняя структуру папок —
   `index.html` должен лежать в корне репозитория). Можно просто
   перетащить файлы в веб-интерфейсе GitHub («Add file → Upload files»),
   либо через git:
   ```bash
   git init
   git add .
   git commit -m "Лендинг Масштабирование VIP"
   git branch -M main
   git remote add origin https://github.com/ВАШ_АККАУНТ/scaling-vip-landing.git
   git push -u origin main
   ```
3. В репозитории: **Settings → Pages → Source** выберите ветку `main` и
   папку `/ (root)`, нажмите Save.
4. Через 1–2 минуты сайт будет доступен по адресу
   `https://ВАШ_АККАУНТ.github.io/scaling-vip-landing/`.
5. Если нужен собственный домен клиента — там же, в Pages, есть поле
   «Custom domain»; понадобится прописать CNAME-запись у регистратора домена.

## UTM-метки

Проверить можно, открыв сайт с параметрами в адресной строке, например:
`?utm_source=vk&utm_medium=cpc&utm_campaign=birthday`
— значения попадут в скрытые поля формы и в payload, который увидите
в консоли при отправке (пока не подключена CRM).
