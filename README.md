# iHappy — главная страница магазина корейской косметики

Тестовое задание: вёрстка главной страницы интернет-магазина с модальными окнами входа и регистрации.

## Структура

```
index.html      — разметка (без инлайн-стилей)
css/style.css   — все стили, переменные цветов в :root
js/main.js      — вся логика
img/            — SVG-иллюстрации товаров, слайдов, логотипы оплаты
```

## Блоки страницы

- Верхняя панель: бесплатная доставка, информационные ссылки, поиск
- Шапка: логотип, телефоны, Вход / Регистрация, избранное, просмотренные, корзина
- Меню каталога с выпадающим пунктом «Акции» (на мобильных — бургер)
- Слайдер акций (5 слайдов, автопрокрутка, стрелки, точки, свайп)
- «Новинки» и «Хиты» — карусели товаров
- «Рекомендации покупателей» — карусель отзывов с рейтингом
- Текст о магазине и блок видео Rutube
- «Вопросы специалисту» — переключение вопросов, «Показать все», «Задать вопрос»
- Подвал: ссылки, контакты, способы оплаты, соцсети, подписка
- Плавающие элементы: «Ваш консультант», кнопка «Наверх»

## Интерактив

- Модалки «Вход», «Регистрация», «Вопрос специалисту»: закрытие по крестику, фону и Esc, валидация полей
- Избранное и корзина обновляют счётчики в шапке и сохраняются в localStorage
- Демо-авторизация без сервера: после входа/регистрации в шапке появляется имя пользователя

Сборка не нужна — достаточно открыть `index.html` в браузере.
